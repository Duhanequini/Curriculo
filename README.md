# 📄 Currículo Pessoal

Este projeto consiste em um **currículo pessoal desenvolvido utilizando HTML e CSS**, criado como parte dos meus estudos e prática no desenvolvimento web.

O objetivo do projeto foi colocar em prática conceitos de **estruturação semântica do HTML, estilização com CSS e organização de páginas web**, além de acompanhar minha evolução durante os estudos.

## 🚀 Sobre o Projeto

O site apresenta informações sobre minha trajetória profissional e acadêmica, meus conhecimentos na área de tecnologia e meus objetivos de carreira.

Atualmente, sou estudante de **Engenharia de Software** e estou em processo de transição de carreira para a área de tecnologia, com o objetivo de me tornar um **Desenvolvedor Full Stack**.
